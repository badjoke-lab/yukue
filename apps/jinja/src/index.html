神社のゆくえ

神社の現在状態、移転・遷座、合祀、再建、管理関係、関連祭礼と、その根拠を記録する専門サイトの実装プレビューです。

Not public. このworkspaceはrepository/local/CI実装専用です。Worker、hostname、route、公開神社レコードは未承認です。

Identity

  • 正式名称・読み・別称・旧称
  • 現在地・旧所在地
  • 公式/公的識別情報

Current state

  • operating / rebuilding / relocated
  • merged / dissolved / unknown
  • 合祀・法人・兼務等は別dimension

Timeline

  • 遷座・移転
  • 再建・被災
  • 合祀・統合
  • 管理・法人・指定変更

Relations

  • 祭のゆくえ
  • 関連神社・寺院
  • 組織・文化財指定

Evidence

  • claim / event / relationごとの根拠
  • Source、確認日、更新日
  • 未確認値は推測しない

Machine-readable

  • identity / state / location
  • relations / events
  • evidence refs / timestamps
